# IZINZNIControllerSuite

**IZINZNIControllerSuite** — это специализированная утилита для настройки, калибровки и маппинга геймпадов в операционной системе Windows. Проект разработан для обеспечения максимальной точности управления и кастомизации игровых контроллеров.

## Особенности / Features
* **Кастомизация управления:** Полный маппинг кнопок, триггеров и стиков.
* **Калибровка стиков:** Настройка мертвых зон (deadzones) для устранения дрифта.
* **Профили настроек:** Возможность создания и быстрого переключения пресетов для разных игр.
* **Поддержка Windows:** Оптимизировано для работы на Windows 10 и Windows 11.

---

**IZINZNIControllerSuite** is a specialized configuration, calibration, and remapping utility for gamepads on Windows. The project is designed to provide maximum control precision and customization for gaming controllers.

## Key Features
* **Gamepad Remapping:** Full configuration of buttons, triggers, and sticks.
* **Stick Calibration:** Deadzone adjustments to eliminate stick drift.
* **Profile Management:** Create and switch presets for different games seamlessly.
* **Windows Compatibility:** Fully optimized for Windows 10 and Windows 11.

## Требования:
  - Windows 10/11 x64
  - Любой геймпад (Xbox, DualShock, DualSense, китайский, Bluetooth)
