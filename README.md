# IZINZNIControllerSuite

**IZINZNIControllerSuite** is a specialized configuration, calibration, and remapping utility for gamepads on Windows. 
The project is designed to provide maximum control precision and customization for gaming controllers.

## Key Features
* **Gamepad Remapping:** Full configuration of buttons, triggers, and sticks.
* **Stick Calibration:** Deadzone adjustments to eliminate stick drift.
* **Profile Management:** Create and switch presets for different games seamlessly.
* **Windows Compatibility:** Fully optimized for Windows 10 and Windows 11.

## Requirements
* Windows 10 / 11 (x64) operating system
* Any gamepad (Xbox, DualShock, DualSense, third-party controllers, Bluetooth / wired connection)
